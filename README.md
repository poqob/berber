# Berber

Berber dükkanı sıra yönetimi PWA'sı. Vue 3 + TypeScript + Tailwind CSS ile geliştirilmiştir.

## Özellikler

- **Sıra Yönetimi** — Müşteri ekleme, koltuğa alma, hizmet bitirme
- **Çoklu Hizmet Seçimi** — Saç, Sakal, Yıkama, Bakım (birden fazla seçilebilir)
- **Canlı Sayaç** — Koltuğa alınan müşterinin süresi otomatik başlar
- **Müşteri Bilgi Sayfası** — Karta tıklayınca bottomsheet açılır
- **Toplu İptal** — Uzun basarak seç, buton ile sıradan çıkar
- **Geçmiş** — Tamamlanan/iptal edilen müşterileri tarihe göre filtrele
- **Tema** — Koyu / Aydınlık tema desteği
- **PWA** — Mobil cihaza ana ekrana eklenebilir, offline çalışır
- **localStorage** — Tüm veriler yerel depoda saklanır

## Stack

- Vue 3 (Composition API)
- TypeScript
- Tailwind CSS 3
- Pinia (state management)
- Vite + Vite PWA Plugin

## Geliştirme

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
